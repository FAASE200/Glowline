**Glowline 0.9.35 — update bridge for 0.9.30**

This release only exists so that **0.9.30 can update itself to the current Glowline**. You don't need to download anything from this page.

### If you are on 0.9.30

Keep automatic updates on. 0.9.30 picks up this release like any other update. When it applies it, the bridge downloads the newest Glowline installer, checks it against GitHub's SHA-256 hash, installs it over your current installation and opens Glowline. Your settings, saved designs and the "start with Windows" option are carried over on the first launch.

If something goes wrong, nothing is changed: 0.9.30 stays installed and tries again on its next check. You can also install Glowline by hand with `GlowlineSetup-<version>.exe` from the newest release.

### If you are on 0.9.40 or newer

Nothing to do: you already have Glowline.

### Files

- `LyricGlowSetup-0.9.35.exe`: the bridge. Only the 0.9.30 updater uses it.
- `Glowline.exe`: a copy of the newest Glowline portable build, attached so that Glowline's own updater recognizes this release and reports it as older.
