**Glowline 0.9.41 Alpha**

### New

- **Translation under each line.** Turn it on in Settings to see every lyric line translated into the app language. It is off by default: the lyrics text is sent once per song to an online translation service (Google Translate, with MyMemory as backup), and the result is kept on your computer.
- **Lyrics on your Discord status.** An optional setting shows the line that is playing instead of the artist (the artist moves to the cover's hover text). Discord limits how often a status can change, so a few fast lines may be skipped.
- **A library for your designs.** Save the current design, apply or delete saved ones from the list, or drop a `.glow` file on the settings window to apply and keep it.
- **More ways to share a line as an image.** Choose the style (cover, cover colors or light) and the shape (post 4:5, story 9:16 or square). The card also shows the translation when it is on.

### Fixed

- **Letters cut off at the end of words.** On the Android app, words in lines that wrapped onto several rows lost their last letter ("qu e guardi n t" instead of "que el guardia no te").
- **Words split into pieces.** When a lyrics source times a word in syllables, a space was added between the pieces ("guardi n"). Spaces now go only where the source puts them. This applies to Windows and Android.
- **Backing vocals that disappeared.** Background vocals lit up in plain white, which can't be read on light backgrounds. They now use the color of the active lyric.

### Android (experimental)

- Smoother full-screen view: it now moves with the screen's refresh rate, and the current line lights up as soon as it starts.
- The current line no longer drifts toward the bottom of the screen as the song goes on, and in the light layout the lyrics start right under the title instead of in the lower half of the screen.
- The cover no longer has a light frame around it, and the light layout has a soft glow in the cover's color, closer to the Windows app.
- This build is a release build (the earlier test builds were slower debug builds).
- The app id changed with the rename, so this APK installs next to the old LyricGlow app instead of updating it. Uninstall the old one if you don't need it.

### Improved

- Lyrics found once are now used when you are offline, even after the usual two weeks.
- While playback is paused, the full-screen view redraws less often.
- The default design name is shown in your language.
- **Discord status shows your player.** Besides Glowline, the status now says which app the music is playing in (for example *Apple Music · Glowline*).
- **Lower CPU use while minimized.** The full-screen view no longer redraws every frame when it is minimized or hidden. In our tests that took the app from about 6% to about 2% of one CPU core while minimized.
- The floating mini lyrics check for changes less often while they are hidden (for example behind the full-screen view). They can take up to half a second to reappear when you leave full screen.
- The updater no longer shows "the release doesn't include the Windows installer" when the newest published release is older than the version you have installed.

### Under the hood

- Code comments, log lines and internal error messages are now all in English. This includes the errors shown when a `.glow` design file can't be imported.

### Upgrading

- **From 0.9.40:** automatic updates install this version for you.
- **From 0.9.30:** the 0.9.35 bridge release installs the current Glowline for you, as long as automatic updates are on. You can also download `GlowlineSetup-0.9.41.exe` below and run it once.

### Downloads

- **Windows installer:** `GlowlineSetup-0.9.41.exe` — **recommended.**
- **Windows portable:** `Glowline-0.9.41-portable.exe` — standalone, no installation.
- **Android (experimental):** `Glowline-0.9.41-android.apk` — install it by hand; it is not offered by the Windows updater.
