**Glowline 0.9.41 Alpha**

### Improved

- **Lower CPU use while minimized.** The full-screen view no longer redraws every frame when it is minimized or hidden. In our tests that took the app from about 6% to about 2% of one CPU core while minimized.
- The floating mini lyrics check for changes less often while they are hidden (for example behind the full-screen view). They can take up to half a second to reappear when you leave full screen.
- The updater no longer shows "the release doesn't include the Windows installer" when the newest published release is older than the version you have installed.

### Under the hood

- Code comments, log lines and internal error messages are now all in English. This includes the errors shown when a `.glow` design file can't be imported.

### Upgrading

- **From 0.9.40:** automatic updates install this version for you.
- **From 0.9.30:** the 0.9.35 bridge release installs the current Glowline for you, as long as automatic updates are on. You can also download `GlowlineSetup-0.9.41.exe` below and run it once.

### Downloads

- **Windows installer:** `GlowlineSetup-0.9.41.exe` — **recommended.**
- **Windows portable:** `Glowline-0.9.41-portable.exe` — standalone, no installation.
- **Android:** no new APK in this release.
